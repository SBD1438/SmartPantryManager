# Smart Pantry Manager: User Guide

## 1. Introduction

Smart Pantry Manager is an Android application that helps users manage pantry ingredients, monitor expiry dates, and find recipes using available ingredients.

## 2. Managing Pantry Ingredients

Users can manage ingredients stored in their pantry.

* **Add:** Enter the ingredient details and save the ingredient.
* **View:** View saved ingredients in the pantry list.
* **Edit:** Select an ingredient and update its details.
* **Delete:** Remove an ingredient that is no longer needed.

Required fields must be completed with valid values.

## 3. Expiry Alerts

The application can display warnings for ingredients that have expired or are approaching their expiry dates.

Users can enable or disable expiry alerts through the Settings screen.

## 4. Recipe Suggestions

The application suggests recipes based on ingredients available in the pantry.

Recipe suggestions consider the ingredients and quantities required. Users can select a suggested recipe to view its ingredients and preparation instructions.

## 5. Data Storage

The application uses SQLite to store pantry information and other application data locally on the device.

Saved information can remain available when the application is closed and reopened.

## 6. Running the Application

1. Open the project in Android Studio.
2. Allow Gradle to finish syncing.
3. Start an Android emulator or connect a compatible Android device.
4. Select the application run configuration.
5. Click **Run** to launch Smart Pantry Manager.
